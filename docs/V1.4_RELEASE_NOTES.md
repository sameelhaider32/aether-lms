# Aether LMS 1.4.0 — Resource collections & bulk export

Download selected resources in a single organized ZIP, with the existing Aether
look and the original Sakai controls intact.

- Mix individual files, nested folders and available courses in one basket.
- Select a folder recursively, then exclude individual children.
- Browse metadata lazily; search discovered filenames and filter file types.
- Review counts, unknown sizes and incomplete discovery before export.
- Stream to a chosen destination, or explicitly use the small ZIP fallback.
- Accept copyright notices individually, cancel an export, and decide whether to
  keep successful files when some resources fail.

Direct output is limited to 2 GiB; the fallback is limited to 64 MiB. Baskets stay
only in the active page and expire after 30 minutes of inactivity. Keep the page
open during export. An account change or Aether OFF clears the basket and cancels
active work. Discovery/downloads do not mark files Opened.

No new Chrome permissions or remote services. All v1.3.1 previews, motion, file
history and native academic operations are preserved. Course coverage depends on
the available Sakai APIs/navigation and is not advertised as every enrollment.

Install/update using the existing unpacked-extension procedure, reload Aether in
Chrome Extensions, and refresh LMS tabs. Authenticated LUMS compatibility and the
OS save-dialog flow still need manual validation. See the architecture and
verification reports for test evidence, limits and security scope.
