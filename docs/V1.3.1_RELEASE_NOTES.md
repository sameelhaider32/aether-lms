# Aether LMS 1.3.1 — Stability and preview reliability

This patch preserves the existing design, particles, course animations, pinned courses, native Sakai controls, assignment colors, attachment previews and resizable readers.

- Clear file history waits for earlier writes across tabs and tool frames.
- Opened/Updated history is scoped to a verified Sakai account. Old unscoped history is discarded safely; interface preferences are retained.
- PDF and Office readers handle close, rapid switching and late loading results safely, with idempotent cleanup and bounded page/slide rendering.
- Failed previews offer Retry preview and retain Open original. Retry never repeats copyright acceptance.
- Unrelated live widgets no longer trigger whole resource-list scans.
- Expanded Windows/Linux fixture, lifecycle, security and 100-cycle stress checks are included.

Reload the extension from the same unpacked folder and refresh LMS tabs. No new permissions or runtime-library upgrades are introduced. History is disabled if the deployed Sakai session API cannot establish identity; previews still work.

This remains a public beta. Authenticated LUMS verification has not been performed. See the audit and verification report for runtime advisory mitigations, measurements and remaining manual checks. No release is automatically published or merged.
